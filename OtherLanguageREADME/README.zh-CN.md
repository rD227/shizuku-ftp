# 使用

不要直接点击启动按钮来生成密钥

没修这个会崩溃的 bug

应该点击左上角，点 Authentication

设置密码

然后启动需要选择一种认证方式

点击右上角，点击 Network status 选择 Shizuku

然后点击启动
